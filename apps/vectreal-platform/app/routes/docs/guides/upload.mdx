# Uploading Models

Everything you need to know about getting 3D files into the Vectreal Publisher.

---

## Supported formats

| Format | Extension(s) | Notes |
|---|---|---|
| **glTF** | `.gltf` + `.bin` + textures | Preferred - full material and animation support |
| **GLB** | `.glb` | Self-contained binary glTF. Single file, easiest to share. |
| **STL** | `.stl` | Geometry only. An STL carries no materials, no scene graph and no textures, so it arrives untextured by definition. |
| **FBX** | `.fbx` | Textures are usually embedded in the file and come through. An FBX that references images beside it instead arrives untextured. |
| **OBJ** | `.obj` + `.mtl` + textures | A bundle, like glTF: the materials live in the `.mtl` and the images beside that. Upload the folder, not the one file. |

STL, FBX and OBJ are read through three.js and converted to glTF before anything else sees them, so what you optimize and publish is a glTF either way. To convert a file without publishing it, see [Converting Between Formats](/docs/guides/convert).

Anything else is rejected with "Unsupported model format", USDZ included. The
Publisher can *write* a USDZ - that is what the [USDZ converter
pages](/docs/guides/convert) offer - but it cannot read one, and it says so up
front rather than failing part way through a parse.

## Upload methods

### Drag and drop

Drag one or more files anywhere onto the Publisher's empty stage. The model loads as soon as the files are parsed.

### File picker

Click **Choose a file** in the middle of the empty stage to open the system file picker. Select your model, and any files it references, together.

### Folder picker

Use **Choose a folder** when the model references files you would rather not select one by one. This opens a directory chooser, and everything in the folder is read. The button is not offered on a narrow screen, since phones have no directory chooser.

### glTF bundles (folder upload)

glTF separates geometry, binaries, and textures into multiple files. To upload a full bundle:

1. Drag the **entire folder** onto the stage, or
2. Use **Choose a folder**, and pick the containing folder, or
3. Select the `.gltf` and its `.bin` and texture files together in the file picker.

The parser identifies the `.gltf` root and resolves all referenced `.bin` and texture files automatically.

## Error handling

| Error | Likely cause | Resolution |
|---|---|---|
| "Unsupported model format. Upload one of: glTF, GLB, STL, FBX, OBJ." | File extension not in the supported list | Convert to one of the formats in the table above |
| "Model references missing assets. Upload the full model folder (including textures/buffers) and retry." | Uploaded `.gltf` without the associated `.bin`/textures | Upload the full folder as a bundle |

---

## Starting a new upload

The stage takes a drop only while it is empty, so there is no drop target inside a scene that already has a model. Open the Publisher without a scene (`/publisher`) to upload a new file. Swapping the model inside an existing scene is not supported.
