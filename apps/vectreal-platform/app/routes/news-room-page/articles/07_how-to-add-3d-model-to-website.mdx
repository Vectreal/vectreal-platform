To put an interactive 3D model on a website, paste a hosted viewer's embed, add Google's model-viewer tag, or use a React component. On Shopify, upload a GLB as product media.

| Route | What you do | Code | Who hosts the model | Fits |
| --- | --- | --- | --- | --- |
| A hosted viewer: Vectreal, Spline or Vectary | Upload the model, paste the embed it gives you | None | The service | Most pages, whoever builds them |
| Google's `<model-viewer>` | Add a script tag and one HTML element | A few lines of HTML | You | A page you edit by hand, with one model |
| A React component | Install `@vctrl/viewer` and give it the file's address | React | You | A React app |
| React Three Fiber or three.js | Build the scene in code | A lot | You | Pages where the 3D is the product |
| Shopify's own 3D slot | Upload a GLB as product media | None | Shopify | Shopify product pages |

## How do I embed a 3D model without code?

Upload it to a hosted viewer and paste the embed it gives you into your page. The service stores the model and draws it, and your page only holds the embed, so it goes wherever your site lets you paste HTML.

**The Vectreal Publisher** is the one I work on, and it's open source (AGPL-3.0).

1. Drop a GLB, FBX or STL file into the [Publisher](https://vectreal.com/publisher?utm_source=newsroom&utm_medium=article&utm_campaign=how-to-add-3d-model-to-website), or the folder that holds a glTF or OBJ.
2. Under **Optimize**, pick a preset. A new scene starts on Original, the file exactly as uploaded. With any of the other three, publishing compresses the model's textures and geometry for the web, and Balanced is the one most scenes want.
3. Pick one of the eight lighting setups and, if you want one, a background. Frame the camera.
4. Publish. You can try everything up to here without an account; saving and publishing need one.
5. Copy the snippet from the **Embed** section. It picks an API key for you, or lets you create one.

Paste it whole. It's an iframe in a sized box, with your project, scene and key already filled in, plus a one-line style rule that lets it fill the space in site builders such as Shopify. The only thing worth changing is the `400px` height:

```html
<style>
  /* Lets the embed fill a bare flex parent, such as a Shopify Custom Liquid block. */
  @layer { div:not([class]):not([style]):has(> .vctrl-embed) { flex-grow: 1; } }
</style>
<div class="vctrl-embed" style="width: 100%; max-width: 100%; height: 400px;">
  <iframe
    src="https://vectreal.com/embed/<projectId>/<sceneId>?token=<your key>"
    style="width: 100%; height: 100%; border: 0;"
    allow="autoplay; xr-spatial-tracking"
    allowfullscreen
  ></iframe>
</div>
```

**Add your site's domain to the project's allowed domains before you ship.** The embed only renders on the domains listed there, and an empty list refuses every other site, even with a valid key. That's also why the key can sit in your page's source: on anybody else's site it doesn't work.

**Spline and Vectary** both import GLB, glTF, FBX, OBJ and STL files, and both give you an embed. Spline publishes a scene as a public link on my.spline.design or as Spline Viewer embed code ([Spline FAQ](https://docs.spline.design/basics/faq.md), [importing content](https://docs.spline.design/importing-content/how-to-import-content)). In Vectary, **Share** and then **Share to Web** gives you a link or iframe code ([Vectary sharing](https://help.vectary.com/documentation/sharing-exporting-embedding/sharing.md), [import formats](https://help.vectary.com/documentation/importing/import-formats)). Both are 3D design tools that run in the browser, so they're also the place to build and animate a scene from scratch rather than show a model you already have.

## How do I add a 3D model to a page with HTML?

```html
<script type="module"
  src="https://ajax.googleapis.com/ajax/libs/model-viewer/4.4.0/model-viewer.min.js">
</script>

<model-viewer
  src="/models/product.glb"
  alt="A 3D view of the product"
  camera-controls
  style="width: 100%; height: 480px;">
</model-viewer>
```

Google's [`<model-viewer>`](https://modelviewer.dev/) is an open-source web component (Apache-2.0). One script tag and one element, and the page shows the GLB you point it at, turned by the visitor's drag. Version 4.4.0, from October 2026, is the current one on [npm](https://www.npmjs.com/package/@google/model-viewer). It's also what draws a 3D model in Shopify's own product gallery: Liquid's [`model_viewer_tag`](https://shopify.dev/docs/api/liquid/filters/model_viewer_tag) emits it.

You host the file, and it shows the file as it is. It doesn't compress anything, so a model straight out of Blender or a CAD tool needs making web-ready first, which [why your 3D models are too large for the web](https://vectreal.com/news-room/optimize-3d-model-for-web?utm_source=newsroom&utm_medium=article&utm_campaign=how-to-add-3d-model-to-website) goes into. The Publisher's **Download** panel also exports a Draco-compressed GLB you can host yourself.

## How do I show a 3D model in a React app?

```tsx
import { VectrealViewer } from '@vctrl/viewer'
import '@vctrl/viewer/css'

export function ProductViewer() {
  return (
    <div style={{ height: 480 }}>
      <VectrealViewer src="/models/product.glb" />
    </div>
  )
}
```

`@vctrl/viewer`, which I work on, is a React component built on three.js and React Three Fiber, for React 19. Give it the address of a GLB, glTF, STL, FBX or OBJ file, and it fetches it, parses it and draws it, with a loader in the meantime. It fills its parent, so give the parent a height. It also takes cameras, hotspots and animation clips as props. Install it with `npm install @vctrl/viewer`.

Two things to know before it goes live. If the file is on another domain, that server has to allow cross-origin reads. And a compressed model needs the Draco and KTX2 decoders, which the viewer looks for at `/draco/` and `/basis/` on your own site unless you point `srcOptions` somewhere else.

If the scene is already published in Vectreal, you don't need a component at all: the embed works in React like anywhere else, and [`@vctrl/embed`](https://vectreal.com/news-room/control-an-embedded-3d-scene-from-your-page?utm_source=newsroom&utm_medium=article&utm_campaign=how-to-add-3d-model-to-website) lets your page switch its cameras and listen to its events. If you build with a coding agent, the Vectreal MCP server lets it publish the model and hand back the embed code: [publish 3D models from your AI agent](https://vectreal.com/news-room/publish-3d-models-from-your-ai-agent?utm_source=newsroom&utm_medium=article&utm_campaign=how-to-add-3d-model-to-website).

## When should I build it with React Three Fiber or three.js?

When the 3D is the product: a configurator, a walkthrough, a scene the rest of the page reacts to. [React Three Fiber](https://github.com/pmndrs/react-three-fiber) is a React renderer for three.js, and with its helper library drei a model takes a few lines:

```tsx
import { Canvas } from '@react-three/fiber'
import { useGLTF, OrbitControls, Environment } from '@react-three/drei'

function Model() {
  const { scene } = useGLTF('/models/product.glb')
  return <primitive object={scene} />
}

export function ProductViewer() {
  return (
    <Canvas camera={{ position: [0, 1, 4], fov: 45 }}>
      <Model />
      <OrbitControls enablePan={false} />
      <Environment preset="studio" />
    </Canvas>
  )
}
```

The ceiling is as high as three.js goes. What it leaves to you is everything around the render: making the file web-ready, hosting it, shadows and lighting that suit the product, and a way for someone who doesn't write code to change the scene after launch.

## How do I put a 3D model on a Shopify product page?

Upload a GLB to the product's **Media** section in the Shopify admin, the way you'd upload a photo. Shopify shows it in the product gallery with its own viewer: no app and no code. It takes GLB and USDZ files up to 500 MB, and the theme has to support 3D models, which all of Shopify's own Online Store 2.0 themes do ([product media types](https://help.shopify.com/en/manual/products/product-media/product-media-types), [adding product media](https://help.shopify.com/en/manual/products/product-media/add-media)).

<video src="/media/images/newsroom/12/shopify-gallery-glb.mp4" autoPlay muted loop playsInline aria-label="A shop product gallery showing a still product photo, which gives way to the same product as a 3D model being turned by hand, then returns to the photo."></video>

If the file is well over the 4 MB or so that Shopify's [modeller checklist](https://help.shopify.com/partners/resources/creating-3d-models/3d-model-standards-checklist) aims for, export it from the Publisher's **Download** panel as a Draco-compressed GLB and upload that instead.

Shopify's viewer draws the file and nothing else. The cameras, lighting and hotspots you set up for a scene don't travel with it, so for those, publish the scene and paste its embed into a **Custom Liquid** section below the product details. [3D on a Shopify product page](https://vectreal.com/news-room/3d-on-a-shopify-product-page?utm_source=newsroom&utm_medium=article&utm_campaign=how-to-add-3d-model-to-website) walks through both, including the allowed domains a store needs: its myshopify.com host and its own domain.

If you're still deciding whether to have a model made, [how to get a 3D model of your product](https://vectreal.com/news-room/how-to-get-a-3d-model-of-your-product?utm_source=newsroom&utm_medium=article&utm_campaign=how-to-add-3d-model-to-website) compares the six ways to get one, from a phone scan to a 3D artist, and [what a 3D model of your product costs](https://vectreal.com/news-room/3d-product-model-cost?utm_source=newsroom&utm_medium=article&utm_campaign=how-to-add-3d-model-to-website) has the prices that studios and freelancers publish.

## What file should the model be?

A GLB: one file that holds the mesh, the materials and the textures, and the format web viewers are built around. [The best 3D file formats for the web](https://vectreal.com/news-room/best-3d-file-formats-for-the-web?utm_source=newsroom&utm_medium=article&utm_campaign=how-to-add-3d-model-to-website) explains why, and how much compressing it saves.

An FBX, OBJ or STL turns into a GLB on the [converter pages](https://vectreal.com/convert?utm_source=newsroom&utm_medium=article&utm_campaign=how-to-add-3d-model-to-website), in the browser and without an account. Keep it small enough for a phone: Shopify's modeller checklist aims for about 4 MB, with textures up to 2048 px.

## Which route should I pick?

- **A Shopify product page:** the product's own 3D slot first, then an embed below it if you want the configured scene.
- **No developer, or a site builder:** a hosted viewer's embed.
- **One model on a page you edit by hand:** `<model-viewer>`.
- **A React app:** a viewer component, or the embed if the scene lives in Vectreal.
- **The 3D is the product:** React Three Fiber or three.js.
