# Uploading Models

Everything you need to know about getting 3D files into the Vectreal Publisher.

---

## Supported formats

| Format | Extension(s) | Notes |
|---|---|---|
| **glTF** | `.gltf` + `.bin` + textures | Preferred - full material and animation support |
| **GLB** | `.glb` | Self-contained binary glTF. Single file, easiest to share. |
| **USDZ** | `.usdz` | Limited support - textures and some material types may not render correctly. Work in progress. |

Anything else is rejected with "Unsupported model format". Convert other formats (OBJ, FBX, STL) to glTF or GLB before uploading.

---

## Upload methods

### Drag and drop

Drag one or more files directly onto the upload area. The model loads as soon as the files are parsed.

### Folder picker

Click the upload area to open the system picker. It selects a whole folder rather than individual files, so put the model and everything it references in one directory first.

### glTF bundles (folder upload)

glTF separates geometry, binaries, and textures into multiple files. To upload a full bundle:

1. Drag the **entire folder** onto the upload area, or
2. Click the upload area and pick the containing folder.

The parser identifies the `.gltf` root and resolves all referenced `.bin` and texture files automatically.

## Error handling

| Error | Likely cause | Resolution |
|---|---|---|
| "Unsupported model format. Upload a .gltf, .glb, or .usdz file." | File extension not in the supported list | Convert to GLB or glTF before uploading |
| "Model references missing assets. Upload the full model folder (including textures/buffers) and retry." | Uploaded `.gltf` without the associated `.bin`/textures | Upload the full folder as a bundle |

---

## Starting a new upload

The upload area is only rendered while no model is loaded, so there is no drop target inside a scene that already has one. Open the Publisher without a scene (`/publisher`) to upload a new file. Swapping the model inside an existing scene is not supported.
